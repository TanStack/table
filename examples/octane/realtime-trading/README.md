# Octane realtime trading

Standalone realtime market-grid benchmark for the TanStack Octane Table adapter.
It intentionally mirrors the Angular, React, Solid, Vue, Svelte, Preact, Lit,
and Alpine examples: the same synthetic worker feed, controls, columns,
selection, sorting/filtering, resizing, column ordering, diagnostics, and
Full DOM/TanStack Virtual row rendering modes.

```bash
pnpm dev
pnpm test:types
pnpm build
```
